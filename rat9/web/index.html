Cómo escribir en el ratón

Enviar un perfil requiere root y toca el ratón. Si el ratón deja de responder, desenchúfalo y vuélvelo a enchufar: el firmware nunca queda alterado, los bloques son de sesión.

El envío se hace desde la CLI, no desde el navegador (el navegador no puede hacer control transfers USB): 

sudo python3 -m rat9.cli send --file perfiles/mi-perfil.pr0

# solo lectura, seguro:
sudo python3 -m rat9.cli status
sudo python3 -m rat9.cli scan
